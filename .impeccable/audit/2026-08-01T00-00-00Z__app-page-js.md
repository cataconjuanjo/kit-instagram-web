### P1 — Fix Before Ship

**P1-1 · Mobile nav keyboard trap** (A11y)  
`PublicNav.js:36` — `<div className="navlinks">` is hidden by `display:none` at `globals.css:6817` on mobile, but the links remain in tab order. A keyboard-only user presses Tab after the hamburger and traverses six invisible nav links.  
**Fix:** Add `aria-hidden={!open}` and `inert={!open ? true : undefined}` to the navlinks div.

**P1-2 · No `prefers-reduced-motion` guard** (A11y + Performance)  
`globals.css:45` — `html { scroll-behavior: smooth }` with no reduction override. All transitions and animations (`.btn`, `.proof-card`, `.service-card`, `backdrop-filter`) run for vestibular-disorder users.  
**Fix:**
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { transition-duration: 0.01ms !important; animation-duration: 0.01ms !important; }
  html { scroll-behavior: auto; }
}
```

### P2 — Fix This Sprint

**P2-1 · LeadForm: no `aria-live` region on state transitions** (A11y)  
`LeadForm.js:55–62` — When `estado` changes to `'sent'` or `'error'`, the DOM subtree swaps silently. Screen readers get no announcement.  
**Fix:** Wrap status output in `<div aria-live="polite" aria-atomic="true">` that persists across all states.

**P2-2 · `transition: width` causes layout thrash** (Performance)  
`globals.css:12861` — `.alta-wizard-bar span { transition: width 400ms ... }`. Animating `width` is not compositor-friendly — triggers layout + paint on every frame.  
**Fix:** Replace with `transform: scaleX()` + `transform-origin: left center`.

**P2-3 · Icon links: conflicting `title` + `aria-label`** (A11y)  
`page.js:282–290` — Each contact icon has both `title="Email"` and `aria-label="Enviar email"`. These disagree and some AT will read both.  
**Fix:** Remove all `title` attributes from the icon `<a>` elements; `aria-label` alone is sufficient.

**P2-4 · Contact section grid collapse gap** (Responsive)  
`globals.css:768` — `minmax(320px, 1fr)` on the LeadForm column means the grid won't collapse below 1080px viewport width. The hero collapses at 900px but contact stays 2-column until 1080px — inconsistent breakpoint behavior.  
**Fix:** Add explicit `@media (max-width: 900px)` rule to stack `.contact-section` to single column.

### P3 — Backlog

**P3-1 · Service grid 2-column at 480px** (Responsive)  
`globals.css:15299` — Collapses to `repeat(2, ...)` at 760px but no 1-column breakpoint below. Cards at 480px are cramped.

**P3-2 · Hardcoded hex values in site-shell overrides** (Theming)  
`globals.css:15166, 15173, 15187, 15205` — `#16100d`, `rgba(255, 250, 241, 0.96)` etc. not mapped to tokens.

**P3-3 · `<aside>` semantics on hero panel** (Implementation Integrity)  
`page.js:92` — The bodega chart panel is a primary illustrative element, not tangential content. Should be `<div>` not `<aside>`.

**P3-4 · Numeric ordinals not aria-hidden** (A11y)  
`page.js:186` — `<span>{num}</span>` ("01", "02", "03") read as "zero one" etc. by AT. Add `aria-hidden="true"`.

**P3-5 · `bodega-ejemplo-badge` redundant aria-label** (A11y)  
`page.js:99` — `aria-label="Datos de ejemplo"` duplicates visible text content. Remove the attribute.

## Systemic Patterns

- **5 side-tab instances** (lines 2800, 5771, 6552, 8166, 11362) — the most recognizable AI-generated UI tell. Needs systematic removal, not case-by-case.
- **1,082 advisory drift items** dominated by literal font-size (597), color (396), and radius (89) values outside the token scale. The CSS has accumulated substantial one-off values. Design token discipline needs a consolidation pass.
- **Inter font at line 52** — flagged as overused in AI-generated UIs. Already superseded by Cormorant Garamond in the `.site-shell` scope, but the base rule exists. Evaluate whether it's still needed anywhere.
